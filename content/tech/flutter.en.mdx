Flutter is Google's open source UI toolkit for building apps for macOS, Windows, Linux, iOS, Android and the web from a single codebase.

We use it when an app has to feel native on every device without building it several times. Paired with a Rust core, Flutter handles the interface while Rust does the heavy lifting. That is how we build [SpaceMan](/cases/spaceman), the [GameNight](/cases/gamenight) phone app and the [atomic.place](/cases/atomic-place) apps.
